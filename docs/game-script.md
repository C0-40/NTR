# 背景（短）

- **阿祿（23）**：骨折靜養的同居主角，玩家視角。腿不好，多半待在家。
- **小櫻（22）**：青梅竹馬，口是心非；媽媽拜託她來照顧阿祿一個月。
- **強叔（41）**：商店街偶遇的中年男人。從「可憐的路人」一路變成小櫻藏起來的另一段關係。
- **時間**：大約一個月的同居。時鐘走完不會自動換日——只有按「睡覺」才進入下一天。
- **第 1～5 天**：純愛節奏為主。強叔親密度不會上升，強叔步驟也不會推進。
- **第 6 天起**：外出回家後，強叔路線的步驟一～四可以開始推進（不必等日常齊）。
- **步驟五鎖**：步驟五及之後必須等全部 **日常／同居事件** 都看過才會開。回憶可另解鎖，但不當這道鎖。
- **室內互動**：每天一次，固定 +5 阿祿親密度。
- **首次提問**：每題第一次點「提問」**不加**親密度。
- **結局**：約第 29～30 天、強叔步驟夠深、日常已齊時，睡覺走進結局選擇。結局一＝告白後仍出軌；結局二＝她搬走跟強叔；結局三＝揭穿真相後的戀人。

# 文案怎麼接上遊戲（給改稿的人看）

玩家一天大致是：在家點對話／輕戳 →（可選）做一次室內互動 →（可選）讓小櫻外出一次 → 外出時可聽心聲、發訊息／打電話／尻槍，或打瞌睡跳過等待 → 她回家可能掛「起疑」「問題」→ 可開提問／聊天室／日常／回憶 → 按睡覺進下一天。彈窗開著時，先看完再做別的。

## 池子怎麼抽（新權重）

- 遊戲用「聲線層」`voiceBand`：取 **強叔步驟地板** 與 **強叔親密度階段** 的較高者。步驟一～二地板為 1；三～八為 2；九以上為 3。
- **強叔步驟已啟動時，不再回抽更低層的純愛心聲／對話**（例如步驟進行中不會再抽「只是去透氣」那種早期句）。外出心聲也不再混入低一階的舊池。
- 半疑心聲（`DOUBT_TH`）在步驟啟動後混入：她隱約覺得強叔的病痛／求助「太剛好」，但因需要被需要而選擇可憐他、對阿祿羞愧——**不是**突然認定他是騙子，也不是厭惡阿祿。
- **起疑（方案 A・地點句內含半疑）**：普通回家的起疑 **只抽一句地點句**——從她剛去的 `PLACE_TRACE-<地點>-*` 依聲線層對應深度抽（`time`＝層 0 最淡，`body`＝1，`item`＝2，`talk`＝3 最濃）。違和感寫進地點細節裡，不再另抽違和池；`TRACE-time/body/item/talk-*` 與偷看池整段停用。**同趟若推進了強叔步驟**，改只顯示該步 `UNCLE_ARC-*-TRACE`。半疑不變：覺得不對勁，仍選擇不深究。
- 提問／她的問題新增「尖銳質問」與「請她別出門」選項；**不會切斷強叔路線**。她的回答帶愧疚，且仍會去／仍可能出門。
- 聊天室匿名串仍保持誇耀、利用口吻，不因她的半疑而變軟。

各塊文案何時出現：

1. **開場**：媽媽訊息 →「不請自來的同居」。
2. **在家對話**：點對話；強叔步驟啟動後改抽 NT／近況句，不再回落早期 TALK 純愛池。
3. **互動**：每天一次；結果句層隨聲線層上修。
4. **外出**：地點心聲／空白行動心聲／步驟心聲／半疑心聲；回家見聞層不低於聲線地板。
5. **提問**：含尖銳質問、挽留別出門等題；首次點題不加親密度。
6. **她的問題**：外出後掛「❓」；選項含尖銳質問與別出門；一天一題。
7. **回憶**／**日常**：親密度門檻；八件日常齊＝步驟五開鎖。
8. **起疑**：方案 A（一句地點句內含半疑，深度隨聲線層；步驟推進日改用步驟專屬痕跡）。
9. **她沒說出口的事**：睡覺時抽心聲池（含半疑）。
10. **當晚**／**聊天室**／**結局**：邏輯同前；聊天室不改誇耀口吻。
