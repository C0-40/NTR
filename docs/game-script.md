# 背景（短）

- **阿祿（23）**：骨折靜養的同居主角，玩家視角。腿不好，多半待在家。
- **小櫻（22）**：青梅竹馬，口是心非；媽媽拜託她來照顧阿祿一個月。
- **強叔（41）**：商店街偶遇的中年男人。從「可憐的路人」一路變成小櫻藏起來的另一段關係。
- **時間**：大約一個月的同居。時鐘走完不會自動換日——只有按「睡覺」才進入下一天。
- **第 1～5 天**：純愛節奏為主。強叔親密度不會上升，強叔步驟也不會推進。
- **第 6 天起**：外出回家後，強叔路線的步驟一～四可以開始推進（不必等日常齊）。
- **步驟五鎖**：步驟五及之後必須等全部 **日常／同居事件** 都看過才會開。回憶可另解鎖，但不當這道鎖。
- **室內互動**：每天一次，固定 +5 阿祿親密度。
- **首次提問**：每題第一次點「提問」**不加**親密度。
- **結局**：約第 29～30 天、強叔步驟夠深、日常已齊時，睡覺走進結局選擇。結局一＝告白後仍出軌；結局二＝她搬走跟強叔；結局三＝揭穿真相後的戀人。

# 文案怎麼接上遊戲（給改稿的人看）

玩家一天大致是：在家點對話 →（可選）做一次室內互動 →（可選）讓小櫻外出一次 → 外出時可聽心聲、發訊息／打電話／尻槍，或打瞌睡跳過等待 → 她回家可能掛「起疑」「問題」→ 可開提問／聊天室／日常／回憶 → 按睡覺進下一天。彈窗開著時，先看完再做別的。

## 池子怎麼抽（新權重）

- 遊戲用「聲線層」`voiceBand`：取 **強叔步驟地板** 與 **強叔親密度階段** 的較高者。步驟一～二地板為 1；三～八為 2；九以上為 3。步驟已啟動時，不再回抽更低層純愛句。
- **心聲（方案 B・兩扇窗）**：**外出**依聲線層分流。**最淡／一層（0–1）**只抽 `PLACE_TH`：她真的去了所選地點（第 1～5 天／層 0＝純愛；層 1＝地點＋半疑）。**二層／最濃（2–3）**不抽地點池：所選地點只是藉口，人在**強叔家**，改抽 `HOME_TH-2`／`HOME_TH-3`（步驟五起：騷擾／債／身體痕跡暗示；對阿祿羞愧，仍選擇可憐他；不直寫過程）。若當日推進了步驟，該步 `UNCLE_ARC-*-TH` **併入當日外出層**（0–1 併入 PLACE_TH；2–3 併入 HOME_TH）。**睡覺**「她沒說出口的事」只抽 `TH`。外出二層／最濃只抽 `HOME_TH`（不再使用地點 `PLACE_TH` 高層）。
- **起疑（方案 A・三層地點句）**：普通回家只顯示一句地點句（`time`／`body`／`item`）；步驟推進日只顯示該步 `UNCLE_ARC-*-TRACE`。與心聲分開：起疑是痕跡，心聲是獨白。
- 提問／她的問題含「尖銳質問」與「請她別出門」；**不會切斷強叔路線**。聊天室仍誇耀、利用口吻。

各塊文案何時出現：

1. **開場**：媽媽訊息 →「不請自來的同居」。
2. **在家對話**：點對話；強叔步驟啟動後改抽 NT／近況句。
3. **互動**：每天一次；結果句層隨聲線層上修。
4. **外出心聲**：層 0–1＝`PLACE_TH`；層 2–3＝`HOME_TH`（人在強叔家，選點是藉口）；步驟日併入對應層；回家見聞另見 `PLACE_EV`。
5. **提問**：含尖銳質問、挽留別出門；首次點題不加親密度。
6. **她的問題**：外出後掛「❓」；一天一題。
7. **回憶**／**日常**：親密度門檻；八件日常齊＝步驟五開鎖。
8. **起疑**：方案 A。
9. **她沒說出口的事**：睡覺只抽 `TH`（半疑／羞愧）。
10. **當晚**／**聊天室**／**結局**：邏輯同前。
