# 背景（短）

- **阿祿（23）**：大學生，玩家視角。兼職時因強叔的緣故受了腿傷，錯過準備已久的實習面試，又被熟悉的同事推卸責任，因此變得被動、防備；目前在家休養，由小紅照顧。人設以 [setting-authority.md](./setting-authority.md) 的最新確認為準；[protagonist-profile.md](./protagonist-profile.md) 僅供參考，遊戲對白尚未全面套用。
- **小紅（22）**：青梅竹馬，口是心非；媽媽拜託她來照顧阿祿一個月。
- **強叔（41）**：商店街偶遇的中年男人。從「可憐的路人」一路變成小紅藏起來的另一段關係。
- **時間**：大約一個月的同居。時鐘走完不會自動換日——只有按「睡覺」才進入下一天。
- **第 1～5 天**：純愛節奏為主。強叔親密度不會上升，強叔步驟也不會推進。
- **第 6 天起**：外出回家後，強叔路線的步驟一～四可以開始推進（不必等日常齊）。
- **第 6～15 天外出**：約 60% 遇見強叔。遇見則去他家幫忙（不能走／屋子亂／只坐一會兒），對阿祿只報所選地點；心聲仍綁地點但含「在他家」又刪掉；起疑用地點對不上的痕跡；剪影出現；強叔親密 +4（第 6 天仍強制 0）；步驟 1～4 可推進且無額外親密。未遇見則真的待在所選地點，心聲／痕跡相符，無剪影，+0，不推進步驟。
- **第 16 天起外出**：必遇；+4；步驟 5 起推進另 +3；人在強叔家（其理由／HOME_TH）。
- **步驟五鎖**：步驟五及之後必須等全部 **日常／同居事件** 都看過才會開。回憶可另解鎖，但不當這道鎖。
- **室內互動**：每天一次，固定 +7 阿祿親密度（上限 100）。
- **首次提問**：每題第一次點「提問」**不加**親密度。
- **結局**：約第 29～30 天、強叔步驟夠深、日常已齊時，睡覺走進結局選擇。結局一＝告白後仍出軌；結局二＝她搬走跟強叔；結局三＝揭穿真相後的戀人。

# 文案怎麼接上遊戲（給改稿的人看）

介面呈現順序及回饋規格見 [presentation-guide.md](./presentation-guide.md)。回家不再停留於對白；「小紅問你」的選項反應在首頁對話框按原有分段逐句顯示，逐字顯示時第一次輕觸補完當句，再輕觸到下一句，最後一句確認後才解除操作鎖定；不改動以下批准原文。

玩家一天大致是：在家點對話 →（可選）做一次室內互動 →（可選）讓小紅外出一次 → 外出時可聽心聲、發訊息／打電話／去廁所，或打瞌睡跳過等待 →「她回來了」顯示原有當晚文本，並可在同窗起疑；當天有外出則隔日才掛「問題」→ 可開提問／聊天室／日常／回憶 → 按睡覺進下一天。彈窗開著時，先看完再做別的。

## 池子怎麼抽（新權重）

- 遊戲用「聲線層」`voiceBand`：取 **強叔步驟地板** 與 **強叔親密度階段** 的較高者。步驟一～二地板為 1；三～八為 2；九以上為 3。步驟已啟動時，不再回抽更低層純愛句。
- **心聲（方案 B・兩扇窗＋早期遇見）**：**第 1～5 天／未遇見**抽 `PLACE_TH`（真的在所選地點）。**第 6～15 天遇見**抽 `EARLY_MEET_TH-*`：心聲仍綁所選地點，但寫出人在他家幫忙，並刪掉「在他家」再回訊。**第 16 天起・聲線層 2–3** 抽 `HOME_TH-2`／`HOME_TH-3`（選點是藉口，人在強叔家）。若當日推進了步驟，該步 `UNCLE_ARC-*-TH` 併入當日外出池。睡覺不再彈「她沒說出口的事」。
- **起疑**：未遇見＝相符的地點 `PLACE_TRACE`（`time`）。第 6～15 天遇見＝`PLACE_TRACE_OFF-*`（地點痕跡對不上）。第 16 天起／步驟更深仍用 `PLACE_TRACE` 的 body／item；步驟推進日可改顯示該步 `UNCLE_ARC-*-TRACE`。與心聲分開：起疑是痕跡，心聲是獨白。
- **外出三動（發訊息／打電話／去廁所）**：每次外出各動作只顯示一句；再點不追加新句（可重看同一句）。**發訊息**：阿祿親密度 ≥25 解鎖（未解鎖仍可見、虛線未使用態）；回得晚或刪行，只露地點名；不阻擋步驟。**打電話**：≥50 解鎖（同樣可見未淡出）；聲音很輕、背景不像店；本趟較不易推進步驟；偏內疚。**去廁所**（標籤；原尻槍行為／💦）：阿祿視角——家裡有女孩，他仍選擇自己解決來忍耐；不影響外出；她不知道。外出心聲頭像在阿祿親密度 ＜25 時霧化，≥25 變清晰（心聲文字仍 ≥50 才可讀）。
- 提問含「尖銳質問」與「請她別出門」；**不會切斷強叔路線**。她的問題是假選項，不改阿祿親密度、強叔步驟或結局。聊天室仍誇耀、利用口吻。

各塊文案何時出現：

1. **開場**：媽媽訊息 →「不請自來的同居」。
2. **在家對話**：點對話；強叔步驟啟動後改抽 NT／近況句。
3. **互動**：每天一次；結果句層隨聲線層上修。
4. **外出心聲**：未遇見／第1–5天＝`PLACE_TH`；第6–15天遇見＝`EARLY_MEET_TH`；第16天起層2–3＝`HOME_TH`；步驟日併入；回家見聞另見 `PLACE_EV`。
5. **提問**：含尖銳質問、挽留別出門；首次點題不加親密度。
6. **她的問題**：前一日有外出，隔日掛「❓」；一天一題。未達門檻的題保持鎖定。選了之後，她的原文反應在首頁對話框逐句顯示；逐字顯示時第一次輕觸補完當句，再輕觸到下一句，全部確認前鎖定其他操作。
7. **回憶**／**日常**：親密度門檻；八件日常齊＝步驟五開鎖。
8. **起疑**：方案 A。
9. **當晚**：保留 `NIGHT`／`FLAT_NIGHT` 事件 ID、原文與抽選規則，改在「她回來了」內顯示，不另開當晚視窗；按起疑後，同窗淡出切換至痕跡，可返回敘述或切回已看過的痕跡，觀察只結算一次。**聊天室**／**結局**：邏輯同前。睡覺直接進下一天，不彈「她沒說出口的事」。

改稿時：同一標題下多行＝可抽候選（非必依序）。標成選項／回答的才是點選順序。
