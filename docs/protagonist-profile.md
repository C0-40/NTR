# 阿祿｜男主人設（已確認）

本檔記錄已確認的人物設定，作為後續改寫開場與同居事件的依據。設定已確立；遊戲內既有對白尚未依本檔全面改寫。玩法與解鎖條件不因此調整。

## 基本身份

- 大學生，已成年；沿用既有設定的 23 歲。
- 小紅久別重逢的青梅竹馬，玩家視角；兩人互有好感，但尚未正式交往。
- 兼職期間腿部受傷，目前需要在家休養。媽媽拜託小紅搬來照顧他。
- 不採用籃球員、校隊或失去運動生涯的背景。

## 受傷與背叛

阿祿以前主動開朗，習慣幫助別人。在強叔的店兼職時，也願意替同事代班、接手麻煩的工作。

一次搬貨時，強叔明知設備有問題，仍要求繼續使用，導致阿祿摔傷了腿。事後，強叔將事故說成阿祿操作不當；當時在場、平日與阿祿交好的同事，為了保住工作，也配合了這個說法。

身體受傷使他需要休養；熟悉的同事推卸責任，才是他失去人際信任的主要原因。他開始認為，別人過去的友善只是因為自己好使喚，自己的善意只會成為被利用的弱點。

## 錯過實習面試

事故發生在一場他準備已久的暑期實習面試之前。阿祿因事發當天需要急診及治療，未能出席。事後聯絡時，該輪招募已結束，沒有補面試的機會。

面試機會的損失加深了他對前途的挫敗感，但不另開求職支線；不把單純行動不便寫成無法參加任何面試，也不額外加入經濟危機、延畢等後果。

## 現在的性格

- 被動與防備是事故後的近期反應，不寫成多年形成的封閉性格。
- 仍能正常交談、開玩笑，也會關心小紅；童年的性格沒有完全消失。
- 不再主動與人深交，不願提出需要，對別人的關心抱有疑慮。
- 起初認為小紅只是受媽媽所託、履行人情，並非真正在乎自己。
- 對未來缺乏信心，但不將他寫成全面消極、沒有選擇能力的人。

## 小紅知道的事情

小紅只知道阿祿因工作意外受傷，不知道強叔與事故有關，也不知道強叔造成腿傷的責任。後續若改變她掌握的資訊，需另行確認，不預先加入揭露時機或反應。

## 同居期間的心理變化方向

小紅不只照顧他的身體，也透過持續的關心，讓他重新相信人的善良。這呼應童年阿祿主動接近小紅、照顧她的回憶：現在換小紅接住他的脆弱。

心理變化應透過相處逐步建立，不靠一次告白立即解決。他開始願意表達需要、接受關心，並重新為自己作打算。

不必讓小紅替他找回實習機會，也不必以面試成功證明康復。後續可討論用整理履歷、重新留意實習資訊等小行動呈現恢復，但具體事件及對白尚未批准。
