# 《小櫻的同居日記》— 遊戲介紹／背景（敘事向）

> 給玩家向理解與寫作延展用。實作細節與禁令見 [HANDOFF.md](./HANDOFF.md)；系統錨點見 [game-outline.md](./game-outline.md)。

---

## 一句話

同居未官宣的日常裡，你透過**心聲、對話變化、外出空白與歸來痕跡**，體驗她被大叔線一點點拉走的 **NTR／患得患失／窺淫**——正戲多半發生在你看不見的地方。

---

## 世界觀

屋子很溫柔：共用牙刷、晚餐、隨口的「今天也要一起吃嗎」。你們是**青梅竹馬**，很久沒見後重逢；互有好感，差一步就能說破，卻還沒成為男女朋友。  
你（**阿祿**）因意外**腿傷不能出門**，多數時間待在家。她（**小櫻**）受**阿祿的媽媽拜託**搬來同居照顧你；她有正當理由出門——便利店、商場、咖啡、加班、朋友聚會。  
門外，一個四十歲上下、時間很多的男人（口中的**大叔／黃毛**）開始出現在她的人生裡。你很少看到他的臉；你看到的是遲到、已讀、香水被蓋過、先沖澡、以及她若無其事地說「我回來了」。

快感不來自「綠帽實況轉播」，而來自：

> **合理出門理由 ＋ 看不見的空白時間 ＋ 可疑歸來痕跡 ＋ 若無其事的同屋日常**

---

## 角色卡

### 阿祿｜玩家
- 青梅竹馬、被照顧的同居者，非男友；對她有明確好感  
- **腿傷不能出門**，長期待在家，靠等她回來認識「門外發生了什麼」  
- 佔有欲與無力感並存：因為「還不是男女朋友」，難以名正言順質問，卻比男友更痛  
- **不要把他寫成渣男**——他越正常、越溫柔、越宅著等，隱奸越成立  

### 小櫻｜女主
- 敏感、討好型；容易把「被需要」當成被愛；擅長合理化  
- 受阿祿媽媽拜託搬來照顧；外出理由正當；與大叔由淺入深後，仍回家維持日常  
- 心聲與日記為**第一人稱私密獨白**——玩家窺的是她的內心，不是全知旁白  
- 可用話術：「我們又不是男女朋友」「這不算」「我只是去幫忙」  

### 大叔／黃毛｜對手
- 少出鏡、少正臉床戲；多以電話、樓下、痕跡、她口中的名字存在  
- 魅力來自**空閒與全部注意力**，不是霸總金權碾壓  
- 遊戲內以好感軸 `m`／`stage` 後台推進；剪影在外出等待時若隱若現（僅氣氛，不可點）  

> 寫作規格檔中的「阿澤／小雨／陳叔」＝同一三角關係的模板名；**本作品正式稱呼以上表為準**。全員明確成年。

## 主題與情緒目標

| 目標 | 玩家該感覺到什麼 |
|--|--|
| **隱奸** | 事情在暗處發生，表面日常還在轉 |
| **NTR** | 「差一步就是我的人」被奪走 |
| **不安** | 知道有事，又無法完全證實 |
| **無限聯想** | 線索夠髒，細節留給腦補 |
| **窺淫** | 門縫、水聲、氣味、已讀、語音殘留、心聲 |

---

## 節奏（玩家體驗）

1. **在家** — 點立繪聊天／長按戳；**室內互動**（關心／看電視／煮飯／桌遊，各花 1 體力）、提問；日記／回憶；事件／紀錄；指針鐘走一日  
2. **外出** — 選地點（小櫻出門、你留家）→ 派出當下**體力回滿** → 空屋壓暗 → 空白行動（傳訊／電話／翻找／尻槍）→ 偶發手機餘波；她在外時不能做室內互動  
3. **歸來** — 痕跡與時間差；「起疑」看細節；可能被問一題  
4. **日記** — 大叔登場後解鎖；歸來後她沒說出口的長獨白（可延遲亮 ✦）  
5. **當晚** — 同屋距離很近，真相仍碰不到；高 `m` 時她可能當面若無其事，對照當日髒痕跡  

一天外出一次；可提早睡覺結日（**只有睡覺才跨日**；時間走完不自動跨日）。睡覺日結後體力回 5。數值上你主要在推兩條線：**她對你的好感 `aff`**，與**她對大叔的好感 `m`**。玩家資源是**體力（最多 5）**，沒有金錢／送禮。

## 內容分級與語氣

- **成人向・隱奸偏重**：可寫情慾，但服務情緒與窺視結構  
- **少直給正戲全程**：優先碎片、聲音、事後、衣物錯位、身體痕跡、腦補與心聲  
- 真要寫較完整性場面，也宜用「事後回溯／不完整記憶／偷聽到的片段」維持窺淫框  
- **禁止**：未成年／幼化；開局就上床；大叔一登場就碾壓搶人；玩家一開始全知  
- 文案必須跟進度走：大叔未登場、stage 仍淺時，不要劇透可疑親密

## 和「紀錄」的差別

| | 日記 | 紀錄 |
|--|--|--|
| 聲音 | 她的第一人稱私密獨白 | 系統／事件流水 |
| 解鎖 | 大叔好感登場後（`m>0`） | 日常可用 |
| 情緒 | 沒說出口的事、自我合理化、慾望與心虛 | 客觀發生過什麼 |
