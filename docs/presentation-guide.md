# 手機網頁呈現規格

## 已確認方向與本輪範圍

- 主要平台為手機瀏覽器／網頁遊戲，保留暖棕奶油色與2D立繪，逐步精修。
- 本輪只執行小紅頭像統一、操作狀態回饋，以及出門／回家／回憶的呈現順序。
- 首頁背景與工具列的整體降噪、互動／外出選單的重複提示精簡，仍是待審閱建議，沒有全面套用。
- 設定與結局修改押後。劇本原文、事件ID、解鎖門檻、相遇機率、加值及結局規則保留。

## 頭像

小紅的心聲、事件、回憶、同居與相關小圖示統一使用根目錄 `xiaohong-normal.png` 的固定裁切，以保持紅髮、服裝與色調一致。頭像不隨心情切換舊圖集；既有霧化門檻保留。強叔男性剪影、母親「媽」字頭像、論壇抽象匿名圖示，以及外出全身剪影的既有規則不變。

## 操作回饋

- 有效按鈕使用短促按壓及確認音，音量設定仍有效。過場鎖定時不重複接受操作或播放按鈕確認音。
- 有效室內互動仍每天一次、固定設定+7、上限100。浮字與互動紀錄顯示實際增加量；例如98→100顯示+2。已達上限時不播放親密度愛心增幅演出，仍正常完成當日互動。
- 「今日已完成」使用實線與較安靜的完成狀態；「尚未解鎖」保留虛線、鎖頭與門檻提示。隔日按既有規則恢復可用或未解鎖狀態。
- 過場顯示短狀態提示；回家閱讀時在對話框顯示「輕觸繼續」，避免操作看似失效。

## 出門

有效操作 → 人物離場 → 建立原有60秒行程 → 顯示原文留言卡 → 關閉留言卡後顯示外出資訊與行動。

離場過程阻擋重複操作。相遇仍由原有判定產生；留言卡閱讀期間不重設行程截止時間，維持原先以截止時間計算的行為。系統減少動態效果時跳過離場動畫，但保留同一閱讀與資訊順序。

## 回家

倒數完成或打瞌睡 → 結算原有行程一次 → 人物回場 → 顯示原有回家文字 → 如有強叔步驟回家對白，逐段顯示 → 依原有佇列顯示後續事件。

回家文字沒有自動略過時限。逐字顯示期間第一次輕觸補全文，再輕觸才前進。強叔步驟原有的回家對白保留，避免直接覆蓋一般回家文字。等待閱讀時不接受其他行動，以免文字被蓋掉或重複結算。

這是呈現順序調整，沒有改寫回家文字、把「當晚」改至睡覺時觸發，亦沒有處理上一輪審查尚待批准的所有敘事一致性問題。

## 回憶

保留一個可捲動視窗、原有標題與說明、逐段淡入，以及點文字立即顯示全文。沒有增加強制閱讀等待或閱讀完成鎖。系統減少動態效果與立即顯示文字設定仍有效。
