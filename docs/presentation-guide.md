# 手機網頁呈現規格

## 已確認方向與本輪範圍

- 主要平台為手機瀏覽器／網頁遊戲，保留暖棕奶油色與2D立繪，逐步精修。
- 紅髮小紅頭像、出門順序、逐句回答反應及操作鎖定沿用既有成果。本輪套用已批准的奶油底色、暖木棕與巧克力描線，灰玫瑰作少量點綴，涵蓋首頁、互動選單與外出頁。
- 保留主要行動的清楚描線與短按壓回饋；資訊層使用較細邊框。互動與外出維持同色，睡覺使用較深暖木色，標示推進日期的不同用途。
- 設定與結局修改押後。劇本原文、事件ID、解鎖門檻、相遇機率、加值及結局規則保留。

## 首頁資訊排版

首頁親密度卡片採條件式對齊：只有阿祿進度條時，卡片靠上；強叔進度條出現後，才與右上「日常／回憶／設定」三個按鈕底部對齊。名稱顯示「阿祿親密度／強叔親密度」，各加心形符號，強叔愛心與其進度條同用灰棕色 `#9b8b72`；數值只顯示目前點數，移除「／100」分母。實際上限、強叔條顯示條件與既有進度計算保留。

## 媽媽開場與立繪待機

新遊戲直接顯示手機介面，媽媽的新訊息通知位於手機內。輕觸查看後，三則既有原文逐段完整彈入，不逐字顯示；段落之間停留1800毫秒，輕觸可加快下一段。每段配專用短雙音訊息提示，沿用音效音量與靜音設定；首次輕觸同時解鎖瀏覽器音訊，不依賴自動播放權限。

三段全部顯示後，提示「輕觸視窗繼續」；點擊視窗即可保存已讀旗標，接續原有小紅入場文本與事件，不設「繼續」按鈕。讀檔保留原有只播放一次的規則；未讀完前讀檔由手機通知重來，重新開始會清除段落計時器。閱讀時首頁暫停操作，長文在訊息區捲動。系統減少動態效果時，段落立即顯示，不播放彈入動畫。

首頁立繪使用獨立 `scale`／`translate` 的5秒呼吸：垂直縮放1至1.008、水平1至1.002，最高點上移1px，增加遊玩時的可辨識程度。不覆蓋原有定位 `transform`，不改圖片素材。既有互動及出入場動作優先，外出時不播放；系統減少動態效果時停用。

## 頭像

小紅的心聲、事件、回憶、同居與相關小圖示統一使用根目錄 `xiaohong-normal.png` 的固定裁切，以保持紅髮、服裝與色調一致。頭像不隨心情切換舊圖集；既有霧化門檻保留。強叔男性剪影、母親「媽」字頭像、論壇抽象匿名圖示，以及外出全身剪影的既有規則不變。

外出心聲頭像使用暗棕底色及四周柔黑放射漸層，保留中央人物色調與原有裁切；邊框不接受點擊。頭像25／心聲文字50的門檻不變。

外出女主剪影採使用者提供的 `NTR game SD.png`，以原始透明 PNG 存為 `sil-hero.png`（1911 × 3920），圖片引用帶有素材版本標記。單人畫面依可用高度等比例顯示全身，保留頭頂及腳部；雙人畫面以不拉伸的半身構圖配合原有強叔半身素材。顯示裁切不修改 PNG 原檔，強叔剪影的原有靠近中心位置、階段及霧化條件保留；心聲與事件頭像仍使用紅髮小紅立繪。

## 操作回饋

- 有效按鈕使用短促按壓及確認音，音量設定仍有效。過場鎖定時不重複接受操作或播放按鈕確認音。
- 有效室內互動仍每天一次、固定設定+7、上限100。浮字與互動紀錄顯示實際增加量；例如98→100顯示+2。已達上限時不播放親密度愛心增幅演出，仍正常完成當日互動。
- 可操作項目保留奶油色按鈕、實線描邊與短陰影。
- 「今日已完成」使用實線、勾號及平面完成狀態；「未解鎖」保留虛線、鎖頭與門檻提示。每日行動已使用時，尚未達門檻的項目仍顯示未解鎖，不改成已完成；隔日仍按既有規則恢復。
- 互動／外出選單不再另加重複的狀態小標籤，保留行動按鈕文字及必要的門檻說明。
- 過場顯示短狀態提示；選項反應閱讀時在對話框顯示「閱讀中」。逐字顯示期間提示「輕觸補全文」，當句完整後提示「輕觸繼續」。其他入口保留實色底並降低對比，表示暫時停用，沒有鎖頭或未解鎖文字。

## 出門

有效操作 → 人物離場 → 建立原有60秒行程 → 顯示原文留言卡 → 關閉留言卡後顯示外出資訊與行動。

離場過程阻擋重複操作。相遇仍由原有判定產生；留言卡閱讀期間不重設行程截止時間，維持原先以截止時間計算的行為。系統減少動態效果時跳過離場動畫，但保留同一閱讀與資訊順序。

## 回家

倒數完成或打瞌睡 → 結算原有行程一次 → 人物回場 →「她回來了」整合視窗 → 依原有佇列顯示後續事件。

不再顯示一般回家對白或步驟回家對白的首頁閱讀停留。舊文字資料與內部紀錄保留供核對，不加入閱讀佇列、不覆蓋首頁對話。這不改變當晚、步驟、觀察等原有結算與事件條件。

「她回來了」取代獨立的「當晚」彈窗，直接顯示當次原有 `NIGHT`／`FLAT_NIGHT` 抽選文本及原有條件追加文字。事件 ID、原文與抽選條件保留，只變更呈現位置。當次已選文本存入 `pendingObs.nightTxt`，關閉、重開及讀檔都不重新抽選。

「起疑」已從首頁移到「她回來了」視窗底部。初次顯示當晚原文及「起疑／繼續」。按下起疑後，內文以140毫秒淡出，再換成原有 `pendingObs.trTxt` 並以140毫秒淡入；畫面背景稍微壓暗，視窗四周加深。每次只展示敘述或痕跡，不再將兩段文字上下堆疊、不另開彈窗，也不重抽內容。系統減少動態效果時立即切換，沒有動畫等待。

觀察完成後，底部只保留「繼續」，標題下方以小字顯示「今日已觀察」，並提供「返回敘述」；返回後同一位置改為「查看痕跡」，可切換重讀。重讀只切換畫面，不再消耗觀察機會。原有觀察資料仍只消耗一次，不增加親密度、強叔步驟、日期或外出次數。

關閉視窗而尚未起疑時，保留當日觀察機會，底部原有「外出已完成」按鈕附上「查看回家」提示，可重開同一視窗；完成觀察後恢復已完成的停用狀態。沒有新增首頁按鈕，也不能因此再次外出。存檔沿用既有 `pendingObs`，睡覺進新天時按原有規則清除。

整合視窗使用頭像／標題列、上方重讀操作與完成狀態、單頁可捲動內文及底部操作列，採深咖啡配色；高度以52svh計算、限制於280～340px，另受85svh的畫面高度上限約束，縮減短文留白。切換前後維持相同視窗尺寸，每頁從頂部開始閱讀。閱讀期間暫停首頁操作，短暫切換期間避免重複按下；關閉、重設或開啟其他事件時取消尚未完成的切換，避免遲到的更新覆蓋其他視窗。關閉後依原有順序顯示其餘同居／回憶及強叔等已排入的事件，不再另開「當晚」。沒有新增或改寫回家劇本。

舊版待觀察存檔若沒有保存 `nightTxt`，不推測或補抽已遺失的當晚文本，仍可查看原有痕跡；之後的新外出會完整保存。舊的記憶體佇列若仍有「當晚」項目，會併入同一視窗。

## 小紅問你的反應

問題與選項仍使用原有彈窗。選擇後關閉彈窗，把該選項的反應按原有對白分段，依序顯示在首頁對話框，每次只顯示一句原有對白，不合併為一段。

每句反應逐字顯示時，第一次輕觸補完當句；再輕觸才顯示下一句。最後一句顯示完整後，再輕觸才結束整組反應。期間鎖定其他行動與入口，文字不會被閒置對話或其他事件自動覆蓋，也不會因時間到而自動解除。完成後才釋放操作並接續原有待顯示事件。立即顯示文字／減少動態效果時，直接顯示當句全文，仍需逐句輕觸繼續。

反應不改親密度、強叔步驟、日期或結局，題目全程只問一次的旗標保留。

首頁日常對話與回答反應共用104px固定對話框；進入閱讀、逐字顯示、補全文、換句及解除鎖定時不改變框高與位置。正文仍為16px；窄螢幕長句在固定文字區內捲動，不向上撐高整個對話框。

## 視覺層級

- 背景奶油色疊層由約30%降至約10%，恢復木色與細節對比；不向人物套用濾鏡或改動人物色調。
- 頂部數值、日期與工具入口使用暖奶油底與較明確暖棕細描線，保留無凸起陰影的次要層級；仍維持原點擊範圍。左上親密度採單層外框、姓名與數值／100在上、6px細橫條在下，避免多層卡片重疊。進度及升階特效始終按實際0～100數值繪製，不切換為階段內比例。
- 對話區正文為一般字重，提升可讀性；標題與數值維持適度加粗。
- 資訊卡採暖奶油平整底色與細邊框；主要行動按鈕使用較深暖棕描線、短陰影。互動與外出使用相同暖奶油配色，睡覺使用較深暖木色。灰玫瑰保留於姓名牌、進度與少量小圖示，正文保持一般字重。
- 外出剪影區使用深咖啡棕；頂部外出狀態卡、倒數中心與速度按鈕，以及發訊息／打電話／去廁所的行動結果框使用深咖啡底、暖奶油色文字及低調暖棕邊線，以增加隱蔽感。底部主要行動仍延續首頁奶油配色。心聲保持深色容器與頭像黑色漸層邊緣，霧化及剪影條件不變。手機畫面按剩餘高度分配剪影區，讓心聲和底部行動保持在畫面內。
- 本輪樣式不套用至設定及結局彈窗。

## 回憶

保留一個可捲動視窗、原有標題與說明、逐段淡入，以及點文字立即顯示全文。沒有增加強制閱讀等待或閱讀完成鎖。系統減少動態效果與立即顯示文字設定仍有效。
