# 源泉圓體 TW

來源為 ButTaiwan 的 GenSen Rounded 2 TW Regular，依 SIL Open Font License 1.1 隨遊戲提供。完整授權見 [OFL.txt](OFL.txt)。字型內的版權與名稱資料均保留。

- 原始檔來自 https://github.com/ButTaiwan/gensen-font/blob/master/otf/TW/GenSenRounded2TW-R.otf
- `gensen-rounded-tw-regular.woff2` 保留現行遊戲使用的字元，供手機優先載入。
- `gensen-rounded-tw-full.woff2` 保留來源完整字元集，遇到常用檔以外的字元時按需載入。
- HTML 使用同一字型家族的兩個字型宣告，常用檔以 `unicode-range` 指定涵蓋範圍。後續新增文字仍可由完整檔顯示。
