# 小賴字體

使用 LXGW 小賴字體 Xiaolai Regular v3.126，依 SIL Open Font License 1.1 隨遊戲提供。完整授權見 [OFL.txt](OFL.txt)，字型內的版權與名稱資料保留。

- 原始字型來自 https://github.com/lxgw/kose-font/releases/download/v3.126/Xiaolai-Regular.ttf
- `xiaolai-regular.woff2` 包含現行遊戲使用的字元，供手機優先載入。
- `xiaolai-full.woff2` 保留來源完整字元集，遇到常用檔以外的字元時按需載入。
- 兩個字型宣告使用同一個字型家族，並以互不重疊的 `unicode-range` 分配字元。後續新增文字可使用完整檔。
